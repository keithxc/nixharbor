# 栖港 · NixHarbor

栖港希望让全球第一次接触 NixOS 的人也能用图形界面管理电脑。第一步是一家软件商店：搜到应用，点一下“安装”，完成后直接“打开”。首批计划适配微信、QQ 和 VLC，优先验证中国大陆网络上的下载与更新，同时提供全球下载来源。

项目目前处于规划阶段。中英文界面、软件商店、桌面设置、系统更新与恢复的交付顺序，以及每一阶段的验收方法，见[中文产品计划书](docs/PRODUCT_PLAN.zh-CN.md)。

## English

NixHarbor aims to make NixOS accessible to first-time desktop users worldwide. The first milestone is a graphical app store where users can find, install and open an app. WeChat, QQ and VLC are the first planned apps. The project will test downloads and updates on mainland Chinese networks as well as a global delivery path. Graphical system settings, updates and recovery will follow. The project is currently in planning.
