# 栖港 · NixHarbor

栖港想让第一次接触 NixOS 的人也能自己管理电脑。装软件、调设置、更新系统，都可以在中文图形界面里完成，全程无需写代码或输入命令。

**项目进度：立项阶段。** 目前尚无可安装版本。

## 第一个目标

让新用户从桌面打开栖港，搜索并安装一款软件，然后从应用菜单启动它。应用更改前，界面会列出将要执行的操作。如果下载中断，用户能看到原因，并在网络恢复后重试。

## 接下来的目标

- **配置电脑**：在界面里选择输入法、调整桌面设置，并预览即将生效的改动。
- **更新与恢复**：查看更新内容和系统版本记录，能从界面选择恢复到先前的系统配置。恢复系统配置与备份个人文件是两件独立的事。
- **在中国大陆下载安装**：为安装介质、软件和系统更新提供可从境内直接访问的下载来源。以中国大陆普通网络上的实际安装和更新结果作为验收依据。

## English

NixHarbor is a planned graphical manager for NixOS. It aims to help first-time users install apps, configure their desktop, update their system and return to a previous configuration. The first milestone is to install and launch one app from the desktop on a mainland China connection. The project is in its planning stage.
